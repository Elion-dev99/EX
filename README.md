# EX Shift

男子学園（dgdgdg.com）のプロフィールページから「出勤スケジュール」を取得し、幹部メンバー分をまとめてカレンダー表示するツールです。

## できること

- 幹部最大6人の公開シフトを横断表示
- 月カレンダーで出勤者を色分け把握
- 日付タップで出勤 / 退勤 / NIGHT / 休みを確認
- プロフィールURLの登録・編集
- 5分キャッシュ付きの再取得

## セットアップ

```bash
npm install
npm run dev
```

ブラウザで [http://localhost:3000](http://localhost:3000) を開きます。

## メンバー設定

初期状態ではつむぎさん（`shop_id=4&boy_id=10235`）のみ有効です。  
画面上の「幹部メンバー設定」から残り5人のプロフィールURLを追加してください。

設定は `data/members.json` にも保存されます。

## API

- `GET /api/shifts` … シフト取得（`?refresh=1` で強制再取得）
- `GET /api/members` … メンバー一覧
- `PUT /api/members` … メンバー更新

## 注意

- 公開プロフィールに載っているスケジュールのみ取得します
- サイト側の公開範囲外の日付はカレンダーに出ません
- 過度な連続リクエストは避けてください
